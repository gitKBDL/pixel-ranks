# Pixel Ranks

Pixel Ranks is a local-first web app for generating Minecraft-style rank badges with custom colors, gradients, and PNG export.

## Features

- Live rank text preview
- Independent controls for background, border, shadow, and text
- Optional gradients with direction control
- Save/open/delete projects in browser storage
- PNG export

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The Vite `base` path is set to `/pixel-ranks/` for GitHub Pages deployment.
